Trama – E-commerce B2C + Mayorista

🎯 Objetivo y problema resuelto

Una tienda de ropa que atiende en el mismo sitio a dos tipos de cliente: quien compra una sola prenda y el negocio que surte su tienda por volumen. El reto era que cada usuario viera el precio correcto según su perfil, la promoción vigente y la cantidad, sin duplicar lógica entre cliente y servidor. Por eso el backend calcula todos los precios y el frontend solo explica por qué ves cada uno.

⚙️ Tecnologías y herramientas

  • Frontend: React 19, Vite, React Router, TanStack Query, Axios, SCSS con BEM estricto
  • Backend: FastAPI (Python), PostgreSQL, SQLAlchemy 2, Alembic, Pydantic, Argon2, PyJWT
  • Integraciones: Mercado Pago Checkout Pro (simulada en el demo) y API de Unsplash
  • Calidad: Vitest, Testing Library, axe-core, Pytest, Ruff, Oxlint y Stylelint
  • Despliegue: Nginx, PM2 y HTTPS con Let's Encrypt

📈 Funcionalidades destacadas

  • Precios dinámicos calculados en el servidor: público, promoción y escalas por cantidad para mayoristas, con cotización al cambiar la cantidad.
  • Carrito para invitados y usuarios que se fusiona al iniciar sesión, con incentivos de envío gratis y de la siguiente escala.
  • Checkout con dirección, envío calculado por el backend y pago con Mercado Pago (simulado en el demo) o contra entrega.
  • Programa mayorista: solicitud con estados, pedido mínimo, panel de beneficios y pedido rápido por referencia.
  • Autenticación con JWT, rutas protegidas y cuenta con pedidos, favoritos, listas de compra e inspiraciones guardadas.
  • Accesibilidad: navegación por teclado, foco gestionado en modales y contraste WCAG AA, auditado con axe en 20 páginas.

Sistema de Gestión de Productos y Usuarios

🎯 Objetivo y problema resuelto

El objetivo principal del proyecto fue crear una solución integral de administración que permitiera a las empresas o equipos técnicos gestionar sus productos, usuarios y roles de forma eficiente y centralizada. Antes, la gestión de permisos y usuarios se realizaba de forma manual y poco estructurada, lo que generaba errores de acceso, duplicidad de datos y falta de trazabilidad. Con esta plataforma, se resolvió ese problema implementando un sistema automatizado de control de acceso, donde cada usuario tiene permisos asignados según su rol, reduciendo riesgos y mejorando la productividad operativa.

⚙️ Tecnologías y herramientas

  • Laravel 10 (PHP)
  • Laravel Breeze
  • Blade Templates + TailwindCSS
  • MySQL
  • Composer y NPM
  • Git / GitHub

📈 Resultados medibles

  • Implementación exitosa de un sistema de roles y permisos totalmente dinámico, que permite escalar el control de acceso sin modificar código.
  • Reducción del tiempo de gestión de usuarios y permisos en más del 60% comparado con un flujo manual.
  • Interfaz intuitiva y responsiva, optimizada para escritorio y dispositivos móviles.
  • Arquitectura modular que facilita la extensión del sistema con nuevos módulos (por ejemplo, reportes, facturación o inventario avanzado).
